2. Données collectées et finalités

Ce site collecte des données via deux formulaires :

  • Formulaire de contact — Données : prénom, nom, email, sujet, message. Finalité : répondre à une demande d'un patient déjà suivi (ce formulaire est réservé aux patients existants). Base légale : consentement explicite. Conservation : 3 ans après le dernier contact.
  • Formulaire de réédition de facture — Données : prénom, nom, email, date de la consultation concernée, montant. Finalité : retrouver et renvoyer par email une facture déjà émise. Base légale : consentement explicite. Conservation : ces données ne sont pas stockées de façon permanente par ce formulaire ; elles sont transmises par email (voir section 5) et peuvent apparaître temporairement dans les journaux techniques du serveur (voir section 5, ligne « Journaux techniques »).

3. Destinataires et sous-traitants

  • Hébergeur : Vercel Inc. (États-Unis) — hébergement du site et des fonctions serveur
  • Envoi des emails : BookMyName (France) — serveur SMTP utilisé pour l'envoi des emails transactionnels (confirmations, factures, alertes)
  • Base de données : Upstash (fournisseur du service Redis utilisé pour stocker les données patients et factures, gérées par ailleurs via l'application de facturation)
  • Mesure d'audience : Vercel Web Analytics — outil de statistiques de fréquentation, sans dépôt de cookie (voir section 7)

Cette liste correspond aux sous-traitants techniques identifiés dans le code de ce site à la date de rédaction. Je ne peux pas garantir l'exhaustivité si d'autres outils (emailing marketing, CRM, etc.) sont utilisés en dehors de ce site — à compléter si c'est le cas.

4. Transferts hors Union européenne

Ce site utilise deux prestataires dont les données sont hébergées aux États-Unis :

  • Vercel Inc. (hébergement du site) — région US
  • Upstash (base de données Redis) — région US

Ces transferts s'appuient sur le Data Privacy Framework UE-États-Unis (DPF), auquel Vercel Inc. et Upstash adhèrent.

6. Vos droits

Vous disposez d'un droit d'accès, de rectification, d'effacement, de portabilité, d'opposition et de limitation du traitement de vos données. Pour exercer ces droits, contactez : cabinet@meignant.net. Délai de réponse : 1 mois.

Vous pouvez également introduire une réclamation auprès de la CNIL (www.cnil.fr).

7. Cookies

Ce site utilise Vercel Web Analytics pour mesurer sa fréquentation. Selon la documentation de son éditeur, cet outil ne dépose aucun cookie : les visites sont identifiées par un hash calculé à partir de la requête entrante, sans lien avec une identité, et les données de session sont supprimées après 24 heures. Aucun autre cookie de suivi, publicitaire ou tiers n'est utilisé sur ce site. En l'absence de cookie nécessitant un consentement, aucun bandeau cookies n'est affiché.
